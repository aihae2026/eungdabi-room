# 응다비:룸 — AI 설문·현장조사 플랫폼 요구사항

## 목적

생활안전점검 서비스 제공인력인 직원이 회원가입 없이 수행기관 공용 링크로 생활안전점검 체크리스트를 제출하고, 전담사회복지사가 제출 결과를 검증한 뒤 정식 대상자 이력으로 등록하거나 확인 완료 처리할 수 있도록 한다.

## 사용자 권한

| 권한 | 주요 역할 |
| --- | --- |
| 중앙 권한 | 낙상, 우울, 기억 체크리스트 설문 폼 생성 및 전국 취합 현황 조회 |
| 광역지원기관 | 소속 시도 내 시군구, 수행기관별 취합 현황 조회 |
| 전담사회복지사 | 수행기관 공용 링크/비밀번호 관리, 제출 결과 검증, 이력 등록, 관리대상 지정 |
| 제공인력 | 비로그인 모바일 화면에서 체크리스트 입력 및 제출 |

## 핵심 업무 흐름

1. 중앙 권한 사용자가 고정 체크리스트를 관리한다.
2. 수행기관 단위로 공용 마스터 링크와 기관 비밀번호가 발급된다.
3. 직원은 공용 링크에 접속해 기관 비밀번호를 입력한다.
4. 직원은 조사자 정보, 대상자 식별 정보, 체크리스트 응답을 입력한다.
5. 시스템은 합계점수를 자동 계산하고 제출 상태를 `확인 대기`로 저장한다.
6. 전담사회복지사는 대시보드에서 제출 결과를 확인한다.
7. 전담사회복지사는 결과를 `확인 완료` 또는 `이력 등록`으로 처리한다.
8. `이력 등록` 처리된 데이터는 대상자 서비스 제공현황 이력에서 조회 가능해야 한다.

## 기능 요구사항

### 공용 마스터 링크 관리

- 수행기관 단위 고유 URL을 자동 생성한다.
- 수행기관 비밀번호를 전담사회복지사가 변경할 수 있어야 한다.
- 공용 링크는 제공인력 회원가입 여부와 무관하게 접근 가능해야 한다.
- 기관 비밀번호가 일치할 때만 체크리스트 입력 화면을 제공한다.

### 모바일 체크리스트 입력

- 로그인 없이 사용할 수 있는 모바일 최적화 UI를 제공한다.
- 대상자 목록, 드롭다운, 사전 개인정보 목록은 노출하지 않는다.
- 조사자는 대상자 성명, 성별, 생년월일을 직접 입력한다.
- 조사자는 조사일자, 조사자 성명, 조사자 전화번호를 직접 입력한다.
- 낙상, 우울, 기억 체크리스트 중 하나를 선택해 제출한다.
- 고연령 제공인력을 고려해 큰 폰트와 넓은 터치 영역을 제공한다.
- 체크리스트별 합계점수를 자동 계산한다.

### 체크리스트

- 낙상 체크리스트: 고정 문항, 합계점수 자동 표기, 미해당 0점 처리
- 우울 체크리스트: 공개 시연용 자체 문항, 합계점수 자동 표기
- 기억 체크리스트: 공개 시연용 자체 문항, 아니오 0점/네 1점 집계

### 검증 대시보드

- 제출 결과는 실시간으로 `확인 대기` 상태 목록에 표시한다.
- 목록 컬럼은 연번, 시도, 시군구, 수행기관, 기관코드, 체크리스트 구분, 조사일자, 조사자명, 총점, 처리상태, 대상자ID, 대상자명, 관리대상 여부를 포함한다.
- 제출 직후 대상자ID와 대상자명은 이력 등록 전까지 공란일 수 있다.
- 전담사회복지사는 제출 건별 관리대상 여부를 Y/N으로 지정할 수 있어야 한다.
- 전담사회복지사는 제출 건을 `확인 완료` 또는 `이력 등록`으로 전환할 수 있어야 한다.

### 검색 및 필터

- 필터 조건: 시도, 시군구, 수행기관, 체크리스트 구분, 조사일자 기간, 처리상태, 관리대상 여부
- 검색 조건: 수행기관, 기관코드, 조사자명, 대상자ID, 대상자명

### 집계 및 통계

- 중앙 권한은 전국 16개 시도, 시군구, 수행기관별 전체 취합 현황을 조회할 수 있어야 한다.
- 광역지원기관은 소속 시도 내 시군구 및 수행기관별 취합 현황을 조회할 수 있어야 한다.
- 수행기관은 소속 수행기관 데이터만 조회할 수 있어야 한다.
- 기간, 지역, 기관 조건별 필터링을 지원한다.
- 모든 목록 및 통계 다운로드는 Excel 형식을 지원한다.
- 조사건수, 대상자수, 확인대기, 확인완료, 이력등록, 평균점수, 점수분포를 제공한다.

## 운영 시스템 추가 고려사항

- 개인정보 암호화 및 접근 로그
- 기관별 권한 분리와 감사 추적
- 대상자 마스터 매핑 및 중복 제출 검출
- 비밀번호 만료, 변경 이력, 접속 제한
- 제출 데이터 원본 보존 및 정정 이력
- 서버 DB, 백업, 장애 복구, 엑셀 다운로드 대용량 처리
